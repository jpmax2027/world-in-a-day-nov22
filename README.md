A Python program that draws a complete newspaper front page for Sunday
22 November 2026 entirely from code — no image files, no network, standard
library only. A small software rasterizer and an embedded 5x7 bitmap font
render the masthead, the COP31 collapse in Antalya as the lead story, panels
on the Kyiv-region drone strike, Iran's strikes at US positions in Bahrain,
the Nigeria funeral-boat toll and the Cikande factory fire, plus a Baltic
ship-fire strip and a news ticker. The finished page is written as a PNG by
a built-in encoder, and two runs produce byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
